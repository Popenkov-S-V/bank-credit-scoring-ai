# 🏦 Анализ кредитных рисков и оценка заемщиков (SQL & Python)

Проект по созданию умной системы, которая помогает банку оценивать надежность клиентов перед выдачей кредита. Модель автоматически проверяет данные человека и предсказывает, вернет он деньги вовремя или нет.

## 📈 Что сделано в проекте и какие результаты:
* **Сбор и очистка данных:** Собрал анкеты более 4400 заемщиков в базу данных SQL (SQLite), удалил ошибки, пропуски и странные скрытые значения в таблицах.
* **Поиск скрытых проблем (Анализ данных):** Нашел важные закономерности. Например, расчеты показали, что молодые люди в возрасте от 18 до 30 лет чаще всего задерживают выплаты по кредитам.
* **Обучение модели (Машинное обучение):** Настроил и обучил математическую модель (Логистическую регрессию), которая на основе возраста, дохода и истории человека оценивает риски для банка.
* **Польза для бизнеса:** Модель научилась угадывать будущие невозвраты кредитов с **точностью 77.44%**. Это помогает банку заранее отсекать ненадежных клиентов и не терять миллионы рублей.

## 🛠️ Стек технологий и инструменты:
* **Базы данных и SQL:** База данных SQLite для хранения всей информации о клиентах.
* **Анализ данных и ML:** Язык Python, библиотека Scikit-Learn для обучения модели и подготовки данных.
* **Понятные отчеты:** Автоматическое создание красивого 6-страничного отчета в формате PDF с графиками для руководства банка.
