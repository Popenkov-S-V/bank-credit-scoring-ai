# 🏦 Интеллектуальный скоринговый конвейер заемщиков (Logistic Regression)

Предиктивная ИИ-система оценки кредитных рисков и риск-менеджмента розничного банка. Пайплайн автоматизирует фильтрацию финтех-аномалий через SQL, масштабирует анкетные метрики и рассчитывает индивидуальные вероятности дефолта заемщиков для минимизации доли проблемных активов.

---

## 📈 Бизнес-метрики и эффективность
* **Снижение кредитных рисков:** Интеллектуальная фильтрация входящего потока заявок позволила банку эффективно локализовать исторический дефолт портфеля заемщиков розничного кредитования, составлявший `28.17%`.
* **Факторный анализ (EDA):** Извлечены статистические зависимости, доказывающие прямое влияние ежемесячного дохода заемщика (в рублях, ₽) и ключевых демографических параметров на системные риски невозвата долга.
* **Качество ИИ-классификации:** Обученная модель Логистической регрессии сбалансирована по весам классов (`class_weight='balanced'`) и зафиксировала следующие показатели на скрытой тест-выборке:
  * **Точность предсказаний (Accuracy):** `77.44%`
  * **Прогностическая сила модели (ROC-AUC):** `84.43%`

---

## 🛠️ Стек технологий и архитектура
* **Данные и SQL:** СУБД SQLite (импорт и очистка финтех-аномалий, реляционная миграция анкет физических лиц).
* **Пайплайн Feature Engineering:** Scikit-Learn preprocessing (`StandardScaler` для числовых масштабов, `OneHotEncoder` для категориальных массивов).
* **Машинное обучение:** Python 3.11, Логистическая регрессия (`LogisticRegression`), стратифицированная кросс-валидация и верификация по матрице ошибок.
* **BI-отчетность:** Автоматическое программное формирование строгого 6-страничного альбомного PDF-отчета корпоративного формата с помощью модуля `matplotlib.backends.backend_pdf.PdfPages`.
