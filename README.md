# 🏦 Анализ кредитных рисков и машинное обучение в скоринге (SQL & ML)

Проект по разработке статистической модели оценки платежеспособности заемщиков для розничного банковского сектора. Система автоматизирует процесс принятия решений по кредитным заявкам, минимизирует риски невозврата (дефолта) и оптимизирует управление банковскими рисками.

## 📈 Что сделано в проекте и какие результаты:
* **Инженерия данных (ETL):** Консолидировал анкетные данные заемщиков (более 4400 строк) в реляционную базу данных SQLite, очистил массив от аномалий и технических пропусков (замена экстремальных значений медианой).
* **Анализ маркеров риска (EDA):** Выявил статистические закономерности дефолтности. Определил зону повышенного риска среди молодых заемщиков (18–30 лет) и подтвердил нелинейную структуру кредитных рисков.
* **Машинное обучение (Machine Learning):** Обучил модель бинарной классификации (Логистическая регрессия) с использованием `StandardScaler` и `OneHotEncoder` для многофакторного анализа. Применил балансировку классов для строгого контроля рисков.
* **Бизнес-результат:** Модель показала высокую точность прогнозирования (**ROC-AUC = 84.43%**, **Accuracy = 77.44%**), что позволяет эффективно блокировать потенциальные дефолты и предотвращать финансовые убытки банка.

## 🛠️ Стек технологий и инструменты:
* **Базы данных и SQL:** СУБД SQLite, выгрузка и фильтрация данных.
* **Data Science и ML:** Python, Scikit-Learn (`LogisticRegression`, `train_test_split`, `StandardScaler`, `OneHotEncoder`, `ColumnTransformer`).
* **Аналитика и Метрики:** Расчет матрицы ошибок (Confusion Matrix), Accuracy и ROC-AUC.
* **BI-отчетность:** Автоматическая генерация 6-страничной бизнес-презентации в формате PDF для департамента управления рисками (Matplotlib, Seaborn).
